Select

Selezione a singola scelta con menu, navigazione da tastiera e filtro opzionale.

Esempio base

Con ricerca (searchable)

Tile selezionabile

Alternativa visiva per una scelta discreta, quando l’opzione beneficia di etichetta, icona o descrizione.

Stati

L'opzione "Semestrale" nell'esempio base è disabilitata singolarmente via OrbitSelectOption.disabled.

Comportamento responsive

Larghezza al 100% del contenitore; il menu a tendina (role="listbox") è posizionato in absolute rispetto al wrapper, non un overlay CDK — su schermi stretti resta ancorato sotto il campo senza riposizionamento automatico.

Accessibilità

  • disabled non è un @Input diretto (stessa asimmetria di orbit-text-input): richiede un [formControl] disabilitato.
  • invalid è un input diretto, indipendente dai form.
  • Navigazione con frecce su/giù, Invio per selezionare, Escape per chiudere il menu.
  • Il menu espone role="listbox"; ogni opzione è un <button> nativo, mai un <div> cliccabile.
