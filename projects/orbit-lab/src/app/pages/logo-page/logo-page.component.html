Come usarlo

Il logo è semplice HTML + CSS. Non servono immagini, SVG o font esterni. Basta il wordmark con font-weight: 800 e il punto span colorato con il token primario. 

<a class="wordmark" href="/lab/" aria-label="Orbit Lab, home">
  ORBIT<span>·</span>Lab
</a>
.wordmark {
  font-weight: 800;
  font-size: 1.15rem;
  text-decoration: none;
  color: inherit;
}

.wordmark span {
  color: var(--orbit-color-primary);
}

Accessibilità

Il link del logo deve avere un aria-label descrittivo. Il <span> con il punto è decorativo e non ha bisogno di testo alternativo.
