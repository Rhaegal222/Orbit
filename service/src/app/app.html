Build with Orbit

A design-token-driven Angular component library built for enterprise applications. Themeable, accessible, and composable.

Why Orbit?

Orbit gives your team a consistent, token-driven design system with first-class Angular support.

Design Tokens

Reference, semantic, and component token layers. Customize once, apply everywhere.

Theme Engine

Dark, light, accent swatches, density presets. Switch via data attributes, zero JS required.

Accessible

ARIA semantics, keyboard navigation, focus management, and screen-reader support built in.

Composable

Standalone components with OnPush change detection. Import only what you need.
