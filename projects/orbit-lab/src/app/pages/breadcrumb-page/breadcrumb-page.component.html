Breadcrumb

Traccia di navigazione gerarchica; oltre una certa lunghezza, gli elementi centrali collassano in un menu "…".

Esempio

Collasso su percorsi lunghi

@if (lastSelectedLabel) {

Ultimo elemento selezionato: {{ lastSelectedLabel }}

}

Accessibilità

  • Struttura semantica <nav aria-label="breadcrumb"><ol>.
  • L'ultimo elemento (pagina corrente) è uno <span aria-current="page">, non cliccabile.
  • Il pulsante "…" apre un popover CDK Overlay con gli elementi nascosti.
