Overflow (scroll orizzontale)

Quando le tab superano la larghezza disponibile, il tablist non le comprime né le fa andare a capo: le tab rimangono visibili e scorrono orizzontalmente. Il contenuto del pannello resta visibile sotto la barra delle tab.

@for (tab of scrollTabs; track tab.value) { } Contenuto della {{ tabLabel(scrollActive()) }}.

Picker modale

In spazi stretti il tablist passa in modalità compact: nasconde le tab, mostra il nome + badge della tab corrente e un pulsante per aprire un selettore a griglia (modale con card di anteprima). Il toggle nella barra compact permette di passare alla modalità offcanvas.

@for (tab of scrollTabs; track tab.value) { } Contenuto della {{ tabLabel(modalActive()) }}.

Picker offcanvas

La variante offcanvas apre un pannello laterale con una orbit-sidebar embedded che elenca le tab come voci di navigazione. Utile quando si preferisce un'interfaccia a lista invece che una griglia di card.

@for (tab of scrollTabs; track tab.value) { } Contenuto della {{ tabLabel(offcanvasActive()) }}.
