Table

Componente presentazionale: il consumer possiede l'iterazione riga e la logica di ordinamento. orbit-table-column emette solo la direzione richiesta; orbitTableRow marca lo stato disabilitato/muted.

Esempio

Nome Stato @for (row of sortedRows(); track row.name) { {{ row.name }} {{ row.status }} }

Varianti

bordered aggiunge bordi verticali e un contorno alla tabella; striped alterna lo sfondo delle righe.

Default

Nome Stato @for (row of rows; track row.name) { {{ row.name }} {{ row.status }} }
