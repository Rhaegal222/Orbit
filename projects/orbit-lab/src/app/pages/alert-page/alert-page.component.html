Alert

Messaggio inline dentro form e card, nel flusso del DOM del chiamante: nessun overlay, nessun servizio.

Contesto d'uso (Inline Form)

Gli Alert compaiono direttamente all'interno del flusso visivo del modulo per informare l'utente di uno stato relativo ai dati.

@if (alertWarningVisible()) { La tua email aziendale non è ancora stata verificata. }

Tone

@if (alertSuccessVisible()) {
Modifiche salvate con successo.
} @if (alertDangerVisible()) {
Impossibile completare l'operazione.
} @if (alertWarningVisible()) {
Controlla i campi obbligatori.
} @if (alertInfoVisible()) {
Sincronizzazione in corso.
}

Dismissible

@if (dismissibleVisible()) { Alcuni campi richiedono attenzione. }

Accessibilità

  • Tone danger usa role="alert"; gli altri tone usano role="status".
  • L'alert non si nasconde da solo: l'output dismissed notifica il parent, che rimuove il componente dal template (pattern "controlled component").
