# Contributors

Orbit was built across multiple private forks before its public release on
npmjs.com. The library would not exist without the work of people who
contributed design tokens, component APIs, accessibility patterns, and
testing infrastructure during that period.

## Pre-release contributors

We are grateful to everyone who shaped Orbit before it became a public
package. Their contributions include:

- Design token architecture and the three-tier token system
- Angular component primitives and form control patterns
- Accessibility audits and keyboard navigation fixes
- Testing infrastructure and visual regression baselines
- Documentation, migration guides, and internal style guides

These contributions happened across private development environments and
are preserved in the commit history of the internal forks that preceded
this public repository.

## How to contribute

Orbit is now open to public contributions. See
[CONTRIBUTING.md](CONTRIBUTING.md) for how to get started.

## Recognition

If you contributed to Orbit during its pre-release development and would
like to be listed by name, open an issue or a pull request with your
preferred name and GitHub profile. We are happy to recognize the work that
made this library possible.
