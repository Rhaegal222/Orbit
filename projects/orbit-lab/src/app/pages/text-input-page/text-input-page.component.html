Leading icon

Le icone semantiche per email, password, ricerca, telefono e URL sono opt-in tramite showLeadingIcon. Currency mantiene invece il simbolo locale, con la stessa superficie della leading icon.

Stati

Comportamento responsive

Larghezza al 100% del contenitore (width: 100% sul wrapper interno): in layout stretti va inserito dentro orbit-form-field o un contenitore di larghezza controllata, non ha un breakpoint proprio.

Accessibilità

  • disabled non è un @Input diretto: si applica solo tramite ControlValueAccessor.setDisabledState(), quindi richiede un [formControl]/[ngModel] disabilitato — a differenza di orbit-checkbox e orbit-pill-switch, che espongono disabled come input diretto.
  • invalid è invece un input diretto, utilizzabile senza un form control.
  • Il tipo password aggiunge un bottone toggle con aria-label dinamico ("Mostra password"/"Nascondi password").
  • inputmode è impostato in automatico in base al type.
